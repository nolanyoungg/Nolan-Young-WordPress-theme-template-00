# Nolan Young Demo Theme 003

A complete classic PHP WordPress studio theme with a sunlit modernist design, accessible image-led mega navigation, and six locally generated photographic assets.

Theme 003 uses concrete, charcoal, jade, lilac, and pale-lemon tones with an indexed editorial layout. Generated project imagery is packaged locally under `dist/images/generated/`; the theme does not depend on remote stock services or placeholder art.

## Commands

- `npm install` installs the locked development dependencies.
- `npm run build` compiles production browser assets.
- `npm run dev` watches source styles and scripts.
- `npm run lint:php` checks every theme PHP file for syntax errors.
- `npm run package` builds and validates the release ZIP in `wp-content/zipped-theme/`.

Edit source in `src/`; do not hand-edit generated files in `dist/css` or `dist/js`.
