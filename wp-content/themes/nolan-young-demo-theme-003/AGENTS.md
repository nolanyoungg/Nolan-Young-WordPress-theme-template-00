## Mandatory local development workflow

The designated WordPress sandbox theme is:

`/Users/nolany/Developer/Sandbox/ny-wp-test-playground/app/public/wp-content/themes/nolan-young-theme-template-99-master`

This sandbox must contain the complete development theme. It must include `build/`, `src/`, `package.json`, `package-lock.json`, `dist/`, and an installed `node_modules/`. A production ZIP or package-only copy is not an acceptable development or visual-testing environment.

Run npm commands from the sandbox theme root containing both `package.json` and `build/`. The `build/` directory contains the Node scripts invoked by npm; it is not itself the npm working directory.

Before theme development:

1. Synchronize the complete repository theme into the sandbox without deleting unrelated WordPress data.
2. Run `npm install` from the sandbox theme root.
3. Run `npm run dev` from the sandbox theme root and keep it running while frontend files are being developed and visually inspected.
4. Synchronize repository source edits into the sandbox before claiming any runtime or visual result.

Before handoff:

1. Ensure the sandbox source matches the repository source under review.
2. Run `npm run lint:php`.
3. Run `npm run build`.
4. Run `npm run package` from the repository theme root so the archive is written to the repository `wp-content/zipped-theme/` destination.
5. Inspect the rendered local WordPress theme after the final build.

Never treat a stripped runtime package as the local development theme, never skip dependency installation, and never claim that unsynchronized repository changes were tested in WordPress.

The only approved command surface for this theme is:

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run lint:php`
- `npm run package`

Do not add `composer.json`, Composer dependencies, PHPUnit, Composer commands, or additional public npm scripts to this theme.
