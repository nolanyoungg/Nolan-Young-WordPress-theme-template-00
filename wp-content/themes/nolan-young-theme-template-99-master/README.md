# Nolan Young Studio 99
A full mock WordPress studio site with local placeholder SVG art.

## Commands
- `npm run build` compiles production browser assets.
- `npm run dev` watches source styles and scripts.
- `npm run package` creates the release ZIP in `dist/`.
- `npm run test` runs lint, build, and theme contract checks before release.

Edit source in `src/`; do not hand-edit generated files in `dist/css` or `dist/js`.
